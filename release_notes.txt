## NeuroCode Android 0.7.2

### Вложения в диалоге
- **Любые файлы в чат** — кнопка прикрепления в поле ввода (скрепка в стандартном дизайне, «+» в новом) открывает системный выбор файлов; можно выбрать сразу несколько
- **Картинки** уходят модели как `image_url` в multimodal-формате OpenAI (нужна vision-модель), до 8 МБ на изображение
- **Текст и код** (txt, md, json, yaml, csv, log, исходники и другие) вставляются в сообщение содержимым, до 24 000 символов на файл
- **Остальные файлы** (PDF, архивы, документы) передаются описанием и путём внутри проекта — агент может открыть их своими инструментами
- Вложения копируются в `.neurocode/attachments` активного проекта: они не попадают в экспорт и синхронизацию, до 32 МБ на файл
- В списке сообщений видны миниатюры картинок, имя и размер файла; выбранное вложение можно снять до отправки
- В локальном режиме (GGUF) текстовые вложения добавляются в контекст, остальные упоминаются по имени

### Размышления модели
- Отдельный сворачиваемый блок «Размышления модели» над ответом; во время генерации раскрыт, после — сворачивается
- Поддержаны оба способа: отдельные поля `reasoning_content`/`reasoning` (DeepSeek, OpenRouter и совместимые) и теги `<think>`/`<thinking>` прямо в тексте
- Размышления сохраняются в истории диалога вместе с ответом
- Разделитель потока переживает разрыв тега между чанками стрима (покрыт unit-тестами)

### Лимиты модели
- Компактная строка над полем ввода: окно контекста, токены последнего запроса и остаток лимитов
- Карточка «Лимиты модели» в настройках: модель, окно контекста, максимум ответа, расход последнего запроса (промпт + ответ), остаток запросов и токенов, время сброса
- Источники — блок `usage` в ответе и заголовки `x-ratelimit-*`; окно контекста берётся из каталога `/models`, если провайдер его отдаёт

### Техническое
- `ChatAttachment` и `reasoning` в модели сообщения, `ModelLimits` в состоянии клиента
- Мультимодальный `content` в запросе OpenAI-совместимого клиента
- versionCode 20

## NeuroCode Android 0.7.1

### Исправления: проекты больше не накладываются друг на друга
- **Диалоги привязаны к проекту** — главная причина «наложения» новых проектов на старые: список чатов раньше был общим, поэтому после создания нового проекта агент продолжал работать со старой историей и переносил файлы предыдущего проекта в новый. Теперь в списке видны только диалоги активного проекта, при переключении открывается его последний диалог, а проект для инструментов агента берётся из самой сессии, а не из текущего выбора
- **Миграция без потери истории** — существующие диалоги без привязки к проекту один раз привязываются к текущему проекту при запуске
- **Папка синхронизации — одна на проект** — привязать одну внешнюю папку к двум проектам больше нельзя (иначе `sync to/from` физически смешивал файлы); показывается предупреждение с именем проекта-владельца
- **Терминал** — сессия перезапускается в корне выбранного проекта, в том числе после фоновой установки proot (раньше shell мог остаться в каталоге прежнего проекта); буфер вывода очищается при переключении проекта

### Оформление: оба дизайна доведены до HTML-референсов
- **Стандартный (GitHub-dark)** — разделители под верхней панелью и над нижней навигацией, бейдж модели с полупрозрачной заливкой и рамкой акцентного цвета, нижняя навигация без «таблетки» Material 3 (акцент цветом иконки и подписи), сплошной зелёный пузырь пользователя (#238636, белый текст), панель ответа агента с рамкой, скругления 10dp
- **Новый (Material 3 Expressive / Gemini)** — шапка с градиентным брендом, кнопками нового диалога, выбора модели и проекта, меню инструментов разработчика (Диалог / Код / Терминал / Git) и шестерёнкой; нижней навигации нет, настройки открываются полноэкранной шторкой с анимацией
- **Чат нового дизайна** — градиентное приветствие, аватар у ответов модели, ответ без подложки, пузырь пользователя со скошенным углом, поле ввода-«таблетка» с круглой кнопкой отправки
- **Терминал и Git нового дизайна** — палитра Gemini: фон #0D0E0F, приглашение `❯`, карточки коммитов с хеш-чипом и пилюлей ветки, diff в цветах #81C995/#F28B82/#8AB4F8

### Техническое
- Диалоги фильтруются реактивно (`combine` сессий и выбранного проекта), активная сессия восстанавливается при смене проекта и удалении чата
- Общий каркас интерфейса разделён на `ClassicTopBar`/`ModernTopBar` с общим меню проектов
- Новые строки локализации (ru/en) для предупреждения о занятой папке, приветствия и заголовков dev-панелей
- versionCode 19

## NeuroCode Android 0.6.0

### Архитектура и совместимость
- **Поддержка ARMv7 (32-бит)** — отдельный APK `armeabi-v7a` с нативной сборкой llama.cpp для 32-битных устройств; компактный debug-APK для arm-v7 собирается в CI
- **Профиль устройства в настройках** — карточка «Этот телефон»: архитектура CPU, число ядер, объём ОЗУ; автоматическое определение архитектуры по SUPPORTED_ABIS
- **Рекомендации GGUF-моделей** — расчёт рекомендованного размера модели под конкретное устройство (ОЗУ, ядра, разрядность) с классом моделей от «только крошечные 0.5B Q4» до «7B+ Q4»
- **Оптимизация под слабые устройства** — на low-RAM/32-бит устройствах автоматически сокращается бюджет генерации локальной модели; предупреждение при импорте GGUF больше рекомендованного размера

### Исправления
- Исправлен падающий smoke-тест CI: тест больше не зависит от языка интерфейса эмулятора (использует строковые ресурсы вместо захардкоженного русского текста)

### APK
- arm64-v8a: для современных устройств (ARM64)
- armeabi-v7a: для 32-битных устройств (ARMv7) — новинка
- x86_64: для эмуляторов и x86 устройств

## NeuroCode Android 0.5.0

### Среда выполнения
- **proot/Linux-окружение** — статический proot 5.4 + Alpine minirootfs устанавливаются по требованию; терминал и команды агента выполняются внутри полноценного user-space Linux (workspace доступен как /workspace), при сбое — автоматический откат на Android shell
- **Языковая подсветка редактора** — Kotlin, Java, Python, JS/TS, C/C++, Go, Rust, Shell, SQL, YAML/TOML/JSON, XML/HTML, CSS и Markdown; выбор языка по расширению файла
- **LSP-клиент** — подключение языкового сервера по stdio (например pyright внутри proot), диагностики ошибок для открытого файла прямо в редакторе

### Интерфейс
- **Локализация ru/en** — весь интерфейс переведён на строковые ресурсы strings.xml (по умолчанию английский, русский включается системным языком)
- Новый раздел настроек «Среда выполнения»: установка/сброс Linux-окружения и настройка LSP

### Исправления
- Исправлены ошибки компиляции в экспериментальном proot-коде (дублирующиеся объявления, suspend-вызовы, распаковка tar без внешнего tar)

## NeuroCode Android 0.4.0

### Новые возможности
- **Пост-проверки агента** — настраиваемые lint/test команды выполняются после правок агента, результат в логе
- **Автоматический fallback провайдера** — при ошибке основного провайдера автоматически повторяет запрос через резервного
- **Импорт/экспорт скиллов** — сохранение и загрузка пользовательских скиллов через JSON-файл (SAF)

- Убрана дублирующая кнопка выбора модели в чате
- Выбор модели перенесен в кликабельный бейдж в topbar (как в HTML-референсе)
- При открытии нового диалога поле ввода остаётся внизу

### Техническое
- AndroidManifest: windowSoftInputMode=adjustResize для корректной работы с клавиатурой
- ModelSwitcherDialog доступен из topbar бейджа

### APK
- arm64-v8a: для современных устройств (ARM64)
- x86_64: для эмуляторов и x86 устройств
