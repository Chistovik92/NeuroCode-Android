# Архитектура NeuroCode Android

## Поток облачного агента

1. Пользователь отправляет задачу.
2. AgentOrchestrator формирует историю и схемы разрешённых инструментов.
3. OpenAiCompatibleClient выполняет HTTPS Chat Completions запрос.
4. Tool call передаётся в AgentTools.
5. Пути проверяет ProjectRepository; запись и shell при необходимости ждут ApprovalGate.
6. Результат инструмента возвращается модели.
7. Цикл продолжается до финального ответа или лимита шагов.

## Локальная модель

GGUF выбирается через системный picker, проверяется по magic header, копируется во внутреннюю папку models и загружается официальным Android binding llama.cpp. JNI и CPU backends собираются NDK непосредственно вместе с APK. Модель в APK не упаковывается.

Локальная модель в версии 0.1 работает в режиме чата и получает содержимое текущего открытого файла до 20 000 символов. Надёжный function calling для произвольных локальных моделей намеренно не имитируется.

## Хранилище

- files/workspaces/UUID — рабочие копии проектов;
- files/state — JSON-метаданные проектов, диалогов и настроек;
- files/secure — AES-GCM ciphertext API-ключей;
- files/models — импортированные GGUF;
- project/.neurocode/history — снимки файлов до перезаписи.

Импорт через Storage Access Framework создаёт рабочую копию. Исходная внешняя папка автоматически не синхронизируется: это исключает неожиданную порчу оригинала агентом.

## Git

JGit работает с обычным .git внутри внутренней копии проекта. Терминал и Git UI независимы: отсутствие бинарного git в Android shell не мешает status, diff, stage и commit в интерфейсе.

## Версия 0.3.3

- темы: `SYSTEM`, `LIGHT`, `DARK`; на широких окнах используется `NavigationRail`;
- список моделей открывается в отдельной прокручиваемой панели с поиском, а не в переполняющемся диалоге;
- контекст проекта агента ограничен путями и размерами файлов без содержимого;
- внешние документы проекта хранятся в `docs/`, `LICENSE` оставлен в корне для GitHub;
- активная модель показывается в top bar как компактный workspace badge;
- синхронизация из внешней папки перед перезаписью создаёт backup в `.neurocode/history`.

## Ограничения 0.3.3

- нет полноценного proot Linux;
- SSH-remote не поддерживаются; HTTPS clone, pull и push доступны через JGit с токеном из зашифрованного хранилища;
- нет Language Server Protocol;
- двусторонняя синхронизация SAF пока не удаляет локальные файлы, отсутствующие во внешней папке;
- конфликт синхронизации пока разрешается в пользу внешней папки, отдельного diff-диалога нет;
- облачный API использует OpenAI-compatible Chat Completions;
- APK не собран с конкретной пользовательской release-подписью.
