## ⚠️ Known Limitations

### Not Implemented
- [ ] **Chat indicator for active filesystem roots** — requires parsing tool_use blocks in chat messages
  - Would need to track which `fs_*` tool calls are using which roots
  - Display small badge/icon in chat UI showing active filesystem access
  - Planned for future enhancement, not blocking 0.8.3

### Edge Cases
- Preset buttons open picker with suggested directory, but user can navigate elsewhere
- Date format is hardcoded to `dd.MM.yyyy`, not localized per device locale
- Migration is one-way: old format cleared after first new root added

## 🔍 Manual Testing Checklist

When you build and test the app, verify:

### Preset Functionality
- [ ] "Downloads" preset opens picker at `/storage/emulated/0/Download`
- [ ] "Documents" preset opens picker at `/storage/emulated/0/Documents`
- [ ] "Pictures" preset opens picker at `/storage/emulated/0/Pictures`
- [ ] "Entire storage" preset opens picker at root external storage
- [ ] User can still navigate to any folder regardless of preset

### Metadata Display
- [ ] Each granted root shows displayName (e.g., "Downloads", "DCIM")
- [ ] Date is displayed in dd.MM.yyyy format
- [ ] URI is shown (truncated if too long)
- [ ] "Revoke" button appears and works for each root

### Migration
- [ ] App upgraded from 0.8.2 shows existing roots without crash
- [ ] Adding first new root migrates old roots to new format
- [ ] Old roots continue working before migration
- [ ] After migration, old format is cleared

### Layout
- [ ] Preset buttons wrap properly on narrow screens (FlowRow)
- [ ] Cards display correctly in both portrait and landscape
- [ ] Long URIs don't break layout
- [ ] Date string fits in all locales

### Tools Integration
- [ ] `fs_list`, `fs_search`, `fs_read`, `fs_import` still work with migrated roots
- [ ] Agent can use granted roots correctly
- [ ] Root limit of 10 is enforced
