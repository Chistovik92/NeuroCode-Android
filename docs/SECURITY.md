# Безопасность

## Модель угроз

AI-ответ считается недоверенным вводом. Модель может ошибиться, предложить разрушительную команду или попытаться получить лишние данные. Поэтому инструменты агента ограничиваются выбранным проектом, а запись и рискованные команды проходят через UI-подтверждение.

## Секреты

- API-ключи шифруются AES-256-GCM.
- Ключ шифрования создаётся Android Keystore и не экспортируется.
- Секреты не входят в экспорт проекта, чат, Git diff и agent tool results.
- Приложение не поддерживает незашифрованные HTTP API endpoint.

## Файлы и команды

- относительный путь преобразуется в canonical path;
- canonical path обязан находиться внутри root активного проекта;
- агент не имеет delete_file;
- файл до перезаписи копируется в .neurocode/history;
- Android shell работает без root под UID приложения;
- подтверждение пользователя не делает неизвестную команду безопасной — сначала прочитайте её.

## Отчёт об уязвимости

Не публикуйте ключи, токены, приватные репозитории и GGUF-файлы в issue. В отчёте достаточно версии, модели телефона, версии Android, stack trace без секретов и минимального сценария воспроизведения.
