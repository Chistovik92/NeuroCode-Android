# Безопасность

Актуально для версии **0.7.5**.

## Модель угроз

AI-ответ считается недоверенным вводом. Модель может ошибиться, предложить разрушительную команду или попытаться получить лишние данные. Поэтому инструменты агента ограничиваются выбранным проектом, а запись, удаление и рискованные команды проходят через UI-подтверждение.

## Секреты

- API-ключи и токены Git remote шифруются AES-256-GCM.
- Ключ шифрования создаётся Android Keystore и не экспортируется.
- Секреты хранятся отдельно от JSON-настроек, не входят в экспорт проекта, чат, Git diff и agent tool results.
- Приложение не поддерживает незашифрованные HTTP API endpoint: только HTTPS.

## Файлы и команды

- относительный путь преобразуется в canonical path (`PathGuard.resolveWithin`);
- canonical path обязан находиться внутри root активного проекта;
- диалог привязан к своему проекту: контекст и правки одного проекта не переносятся в другой;
- одна папка синхронизации принадлежит только одному проекту;
- запись и замена файлов, `delete_file` и `run_command` проходят через `ApprovalGate`; удаление и
  рискованные команды (рекурсивное удаление, системные команды, `curl | sh`, `find -delete/-exec`,
  `sed -i`) помечаются как деструктивные;
- файл до перезаписи или удаления копируется в `.neurocode/history`;
- внешние инструменты пользователя запускают только заранее заданную команду и тоже требуют подтверждения;
- вложения копируются в `.neurocode/attachments`, размер ограничен (32 МБ на файл, 8 МБ на изображение);
- Android shell работает без root под UID приложения; Linux-окружение (proot) — user-space, без root;
- подтверждение пользователя не делает неизвестную команду безопасной — сначала прочитайте её.

## Разрешения Android

В манифесте объявлено только `INTERNET`. Доступ к внешним папкам возможен лишь через системный выбор
(Storage Access Framework) для импорта, экспорта и синхронизации. Модель не может читать файлы вне проекта.

## Планируемые расширения и требования к ним

Описаны в [ROADMAP.md](ROADMAP.md); при реализации действуют следующие правила.

- **Доступ к файловой системе (0.8.1):** по умолчанию закрыт; только явно разрешённые корни; поиск и
  чтение без подтверждения, запись и удаление вне проекта — только с подтверждением и полным путём;
  `Android/data` и `Android/obb` исключены.
- **Загрузка GGUF с Hugging Face (0.9.1):** только HTTPS; сверка SHA-256 и проверка заголовка GGUF
  до активации модели; токен Hugging Face (для закрытых моделей) хранится в Keystore; характеристики
  устройства для подбора считаются локально и не отправляются.
- **MCP-коннекторы (0.10.0):** только HTTPS, токены в Keystore, каждый вызов внешнего инструмента
  подтверждается, ответы серверов считаются недоверенным вводом и ограничиваются по размеру.
- **Плагины (0.10.1):** пакеты без исполняемого кода; запрашиваемые права показываются до установки.
- **Управление телефоном (0.10.2):** `AccessibilityService` выключен по умолчанию, действия по шагам с
  подтверждением, кнопка аварийной остановки, запрет на ввод паролей и платёжных данных.

## Отчёт об уязвимости

Не публикуйте ключи, токены, приватные репозитории и GGUF-файлы в issue. В отчёте достаточно версии, модели телефона, версии Android, stack trace без секретов и минимального сценария воспроизведения.
