# План версии 0.9.2 — скиллы и внешние инструменты

Статус: **выполнен** (ветка `0.9.2`, versionCode 38). Связанный документ: [ROADMAP.md](ROADMAP.md) (раздел 0.9.2).

Сейчас: скилл (`AgentSkill`: имя + текст) добавляется в системный промпт агента; внешний
инструмент (`ExternalAgentTool`: имя, описание, команда) — вызов команды с подтверждением.

---

## Что сделано

- [x] **Чистая сборка блока скиллов** — `SkillPrompt.kt`: `active()`/`lines()`/`block()`.
  Правила: глобальный переключатель `skillsEnabled`, учёт `enabled`, область `PROJECT`
  только в своём проекте. Используется и в облачном (`CloudRequest.skills`), и в локальном
  (`runLocal`) запросе.
- [x] **Локальная модель получает скиллы.** `runLocal` добавляет блок «Активные навыки» в
  системный промпт движка — решение по открытому вопросу из плана.
- [x] **Поля скилла** — `AgentSkill` расширен: `description`, `tags`, `scope` (`GLOBAL`/`PROJECT`),
  `projectId` (с дефолтами, обратная совместимость JSON).
- [x] **Библиотека готовых скиллов** — `SkillLibrary.kt`: код-ревью, тесты, коммиты, рефакторинг;
  установка в один тап из «Настройки → Скиллы».
- [x] **Импорт `SKILL.md`** — `SkillImport.kt`: заголовок `# Имя` — название, строки
  `> description:`/`> tags:` — метаданные, остальное — текст; плюс JSON-импорт (прежний).
- [x] **Предпросмотр промпта** — кнопка «Предпросмотр промпта» показывает блок активных навыков.
- [x] **UI** — описание/теги в карточке скилла, поле «только проект», секция библиотеки.
- [x] **unit-тесты** — `SkillPromptTest`: глобальный переключатель, выключение, область проекта,
  формат `имя: prompt`, пустой блок, библиотека, парсер SKILL.md, сериализация новых полей.

## Примечания

- Проверка «скилл влияет на ответ» и внешний инструмент с подтверждением/отказом — на устройстве
  (требуют живого провайдера/`Context`); логика вынесена в тестируемый `SkillPrompt`/`SkillMarkdown`.
- Полноценный перевод внешних инструментов на unit-тесты (`AgentTools.executeExternal`) — с
  Robolectric, вместе с остальными требующими Android тестами (см. PLAN-0.9.0, часть 2.4).
