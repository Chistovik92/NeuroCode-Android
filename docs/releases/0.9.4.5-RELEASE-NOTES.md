# NeuroCode Android 0.9.4.5 Release Notes

**Дата релиза:** 7 ноября 2026
**Версия:** 0.9.4.5 (versionCode 41)
**Тема:** совместимость с LocalDoc AI

## Исправлено

- Модели LocalDoc AI снова отображаются: учитываются release- и debug-провайдеры `<applicationId>.models`, включая одновременно установленные сборки.
- Исправлено чтение стандартной колонки `_id` и открытие модели по её исходным authority и `id` совместно с LocalDoc AI 2.9.1+.
- Полный межпроцессный цикл «список → открытие → GGUF header» проверен на Android-эмуляторе.
- Device-тест пропускает интеграционную проверку, если LocalDoc AI с моделью не установлен, поэтому общий CI-эмулятор не зависит от внешнего APK.

## Проверка

- Локально: unit-тесты, detekt, `assembleDebug`, подписанный `assembleRelease`.
- GitHub Actions: unit-тесты, detekt, debug/release APK и instrumented smoke-тесты.
- Release: https://github.com/Chistovik92/NeuroCode-Android/releases/tag/v0.9.4.5
