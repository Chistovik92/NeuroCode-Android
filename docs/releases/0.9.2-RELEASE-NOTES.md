# NeuroCode Android 0.9.2 Release Notes

**Версия:** 0.9.2 (versionCode 38)
**Тема:** скиллы и внешние инструменты

## Что нового

### Скиллы стали полноценными

- **Описание и теги.** У каждого скилла появились короткое описание и теги — они видны в списке
  «Настройки → Скиллы».
- **Область действия.** Скилл может быть глобальным или действовать только в одном проекте.
- **Библиотека готовых скиллов.** Код-ревью, «Пиши тесты», «Чистые коммиты», «Безопасный
  рефакторинг» — устанавливаются в один тап.
- **Импорт `SKILL.md`.** Помимо JSON, скилл можно импортировать из файла формата `SKILL.md`
  (заголовок `# Имя` + текст инструкции).
- **Предпросмотр промпта.** Кнопка «Предпросмотр промпта» показывает блок активных навыков,
  который получит модель.

### Локальные модели учитывают скиллы

Раньше скиллы формировались только для облачного запроса. Теперь блок «Активные навыки»
добавляется и в системный промпт локальной GGUF-модели.

### Под капотом

- Сборка блока скиллов вынесена в чистую, тестируемую логику `SkillPrompt` (глобальный
  переключатель, включение/выключение, область проекта).
- Покрыто unit-тестами (`SkillPromptTest`): сборка блока, переключатели, область действия,
  парсер SKILL.md, библиотека, сериализация новых полей.
