# NeuroCode Android 0.8.7 Release Notes

**Дата релиза:** 5 ноября 2026
**Версия:** 0.8.7 (versionCode 34)
**Тема:** удобный выбор моделей — только подключённые провайдеры и локальные GGUF в одном окне

## Что нового

Окно выбора модели переработано: оно больше не предлагает провайдеров, которыми
нельзя воспользоваться, и объединяет облачные и локальные модели в одном списке.

### Только провайдеры с подключённым API-ключом

В роутере выбора модели теперь показываются только облачные провайдеры, у которых
задан (непустой) API-ключ. Провайдер без ключа не отображается, а если ключа нет ни
у одного провайдера, вместо неудачного запроса к API показывается подсказка с
предложением добавить ключ в настройках. При открытии окна сразу выбирается
подключённый провайдер (активный, если у него есть ключ, иначе первый подключённый).

### Локальные GGUF-модели — отдельная группа

Импортированные локальные модели выделены в отдельную группу «Локальные (GGUF)» и
выбираются из того же окна, что и облачные — переключение между провайдерами и
локальным режимом одной строкой роутеров.

### Самостоятельная прокрутка списка

Список моделей стал отдельной прокручиваемой областью: заголовок, текущая модель,
роутеры и поиск закреплены и не смещаются при прокрутке. Для выбранного роутера
разделены состояния загрузки, пустого списка и ошибки.
