# NeuroCode Android 0.9.1 Release Notes

**Версия:** 0.9.1 (versionCode 37)
**Тема:** автоматическая загрузка подходящих GGUF с Hugging Face + устойчивость

## Что нового

### Каталог моделей и подбор под телефон

В разделе «Модели на устройстве» появился блок **«Рекомендовано для этого телефона»**: встроенный
проверенный каталог из 15 моделей Q4_K_M (0.5B–7B — Qwen, Gemma, Llama, Phi, SmolLM, DeepSeek,
Vikhr). Приложение само считает по `DeviceProfile` (ОЗУ, ядра, архитектура, `maxModelSizeMb`),
какие модели потянет именно это устройство, и показывает их с кнопкой «Скачать» в один тап.
Модели, которые не помещаются, помечаются «слишком большая», а не скрываются.

### Загрузка с Hugging Face

- Поиск моделей через публичный API Hugging Face (`/api/models` с фильтром `gguf`), список файлов
  репозитория и выбор квантизации (по умолчанию наибольшая из Q4_K_M → Q5_K_M → Q8_0, что
  помещается в рекомендованный размер).
- Скачивание по `/<repo>/resolve/main/<file>` с докачкой по HTTP `Range` (после обрыва/перезапуска
  недокачанный `.part` дополняется), сверкой SHA-256 с данными LFS, проверкой magic GGUF и
  переносом в `files/models`.
- Опция «только по Wi‑Fi» для больших загрузок.
- Закрытые (gated) модели: необязательный токен Hugging Face, хранится в Keystore (как ключи API).
- После загрузки модель становится активной локальной моделью.

Только HTTPS; список и скачивание не отправляют на сервер данные о диалогах, характеристики
устройства считаются локально.

### Устойчивость

- Исправлен неатомарный read-modify-write стриминга ответа (`_streamingResponse.update`) —
  дельты не теряются при параллельной эмиссии.
- Очистка spill-файлов старше 7 дней при старте — каталог `.neurocode/spill` больше не растёт
  неограниченно.
