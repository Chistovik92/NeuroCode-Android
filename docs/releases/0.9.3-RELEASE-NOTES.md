# NeuroCode Android 0.9.3 Release Notes

**Версия:** 0.9.3 (versionCode 39)
**Тема:** цикл агента из DeepSeek Harness

## Что нового

- **Режим планирования** — агент составляет план, пользователь одобряет его или возвращает с замечаниями; до одобрения запись и команды запрещены.
- **Цель и список задач** — чек-лист виден в чате и переживает перезапуск, цель проверяется перед завершением.
- **Вопросы пользователю** — уточнения с вариантами ответов и необязательным timed-режимом.
- **Субагенты** — подзадача выполняется в отдельном контексте и возвращается сводкой; используется модель родительского запроса.
- **Фоновые задачи** — долгие команды запускаются в фоне, вывод читается, процесс можно остановить. Системное уведомление о завершении остаётся в backlog.
- **Workflow** — сохранённая последовательность шагов агента запускается по кнопке.
- **Политика разрешений** — проверка пути, политика, подтверждение, запуск и журнал объединены в один конвейер.
- **Результаты** — `present` показывает итоговый файл карточкой с открытием.

## Проверка

- Unit-тесты, detekt, debug/release-сборки и instrumented smoke-тесты в CI.
