# NeuroCode Android 0.9.4 Release Notes

**Версия:** 0.9.4 (versionCode 40)
**Тема:** провайдеры, пресеты и настройки

## Что нового

- **DeepSeek** — API-ключ, каталог моделей, `reasoning_content`, префиксный ответ и учёт кэша контекста поверх OpenAI-совместимого API.
- **Свой OpenAI-совместимый провайдер** — загрузка `/models` и проверка ключа с выбранной моделью до сохранения.
- **Пресеты агента** — модель, скиллы, внешние инструменты и политика в именованном наборе; приоритет «диалог → проект → глобально».
- **Единые секреты** — ключи провайдеров, Git/MCP-токены и Hugging Face используют общий интерфейс поверх Android Keystore и не попадают в JSON или экспорт.
- **Все настройки** — типизированный каталог, версия схемы, миграция старых корней доступа и поиск по названию, ключу и значению.

## Проверка

- 187 unit-тестов, detekt, debug/release-сборки и instrumented smoke-тесты в CI.
