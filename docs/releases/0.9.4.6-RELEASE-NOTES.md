# NeuroCode Android 0.9.4.6 Release Notes

**Дата релиза:** 7 ноября 2026
**Версия:** 0.9.4.6 (versionCode 42)
**Тема:** модели LocalDoc AI напрямую, без копирования

## Добавлено

- **Модели LocalDoc AI используются напрямую.** GGUF грузится по файловому дескриптору провайдера
  (`/proc/self/fd/<fd>`), без копирования в `files/models`. В «Моделях на устройстве» действие
  «Использовать» вместо «Импортировать», у активной модели — индикатор.
- Новый `ModelKind.LOCAL_DOC` и поля `ModelRef.localDocId/localDocAuthority`; активная модель
  хранится в `AppSettings.localDocModel*`, выбор через `ModelResolver` понимает прямую ссылку.
- Дескриптор держится открытым до выгрузки и закрывается в `unload()`/при смене модели.
- Проверка читаемости файла в движке llama пропускается для `/proc/self/fd/` — открытый
  дескриптор сам доказывает читаемость.

## Проверка

- Локально: unit-тесты (включая новые для `LOCAL_DOC`), detekt, `assembleDebug`.
- GitHub Actions: unit-тесты, detekt, debug/release APK и instrumented smoke-тесты.
- Совместимость: LocalDoc AI 2.9.2 (versionCode 34).
