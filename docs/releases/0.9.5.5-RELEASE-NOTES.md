# NeuroCode Android 0.9.5.5 Release Notes

**Дата релиза:** 28 ноября 2026
**Версия:** 0.9.5.5 (versionCode 44, хотфикс вне общего порядка версий)
**Тема:** провайдер AI Star, дополнительные модели провайдера, понятные ошибки загрузки GGUF

## Добавлено

- **Провайдер AI Star (ai.starimg.ru)** — порт `src/aistar.ts` расширения
  [winOpenCodeMod](https://github.com/Chistovik92/winOpenCodeMod):
  - AI Star добавлен в стандартные провайдеры (OpenAI-совместимый, доступ по коду активации);
  - в диалоге провайдера: поле кода доступа и кнопка «Активировать код» — ключ `sk-star-…`
    получается автоматически (POST формы с CSRF-токеном со страницы), без ручного копирования;
  - кнопка «Загрузить список моделей» — каталог со публичной страницы AI Star
    (`window.__STARIMG_BOOTSTRAP__`, 57 моделей в 10 категориях на момент проверки), ключ не нужен;
  - `base_url` региона из ответа активации сохраняется в провайдере.
- **Дополнительные модели у любого провайдера** — по образцу строк «models» кастомного
  провайдера winOpenCodeMod: в диалоге провайдера можно добавить строки с новыми моделями
  (id + кнопки добавить/удалить). Ручные модели появляются в списках выбора модели в чате
  вместе с основной и каталогом из API — даже если запрос каталога не удался
  (`ProviderConfig.extraModels`, слияние в `ModelSwitcherDialog`).

## Исправлено

- **Понятная ошибка неподдерживаемой архитектуры GGUF.** Раньше при загрузке локальной модели
  с неподдерживаемой архитектурой показывался сырой тост с именем класса
  (`UnsupportedArchitectureException`) без текста. Теперь сообщение человекочитаемое и называет
  архитектуру из GGUF-метаданных, например: «Модель использует архитектуру «qwen35», которая
  не поддерживается этой сборкой llama.cpp».
- **Движок больше не «залипает» в ошибке.** После неудачной загрузки модели состояние движка
  оставалось `State.Error` до перезапуска приложения, и любая следующая модель не загружалась.
  Теперь ошибка сбрасывается автоматически (`load`/`loadLocalDoc`/`unload` в `LocalLlamaClient`),
  повторная загрузка работает без перезапуска.

## Проверка

- Локально: unit-тесты (включая новые `AIStarClientTest` — разбор bootstrap, активация,
  слияние моделей), detekt, `assembleRelease`.
- Разбор bootstrap-каталога AI Star проверен на живой странице (PowerShell, 27–28.11.2026).
