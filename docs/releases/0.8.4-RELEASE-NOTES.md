# NeuroCode Android 0.8.4 Release Notes

**Дата релиза:** 4 ноября 2026
**Версия:** 0.8.4 (versionCode 31)
**Тема:** Исправление краха при запуске

## Что нового

### Исправлен крах приложения при запуске (критический баг 0.8.3)

В версии 0.8.3 приложение падало сразу после запуска (`NullPointerException`)
на всех устройствах. Релиз 0.8.2 не был затронут.

## Причина краша

`SettingsViewModel` (экран настроек) в блоке `init` запускал корутину,
которая подписывалась на поток настроек и обновляла `_fsRootsMeta` —
список корней файловой системы с датами выдачи (новое поле 0.8.3).

Проблема: `viewModelScope` использует `Dispatchers.Main.immediate`,
поэтому `settings.collect { ... }` внутри `viewModelScope.launch`
выполнялся **синхронно** прямо в `init`, а поле `_fsRootsMeta`
было объявлено **ниже** блока `init` — в этот момент оно ещё было `null`.

В момент первой эмиссии настроек (сразу, StateFlow) присвоение
`_fsRootsMeta.value = ...` падало с NPE. `AppViewModel` наследует
`SettingsViewModel` и создаётся при старте приложения, поэтому краш
возникал на любом запуске, даже без захода в настройки.

```
java.lang.NullPointerException: Attempt to invoke interface method
'void kotlinx.coroutines.flow.MutableStateFlow.setValue(java.lang.Object)'
on a null object reference
    at SettingsViewModel$2$1.emit(SettingsViewModel.kt:53)
    at SettingsViewModel.<init>(SettingsViewModel.kt:50)
    at AppViewModel.<init>(AppViewModel.kt:23)
```

## Решение

Поле `_fsRootsMeta` (и data-класс `FsRootMeta`) объявлено **до** блока `init`,
теперь синхронный `collect` ссылается на уже инициализированное поле.

Исправлено на 0.8.3:
```kotlin
init {
    viewModelScope.launch {
        settings.collect { appSettings ->
            // _fsRootsMeta ещё null — NPE
            _fsRootsMeta.value = ...
        }
    }
}

private val _fsRootsMeta = MutableStateFlow<List<FsRootMeta>>(emptyList())
```

Исправлено в 0.8.4:
```kotlin
private val _fsRootsMeta = MutableStateFlow<List<FsRootMeta>>(emptyList())

init {
    viewModelScope.launch {
        settings.collect { appSettings ->
            // _fsRootsMeta уже инициализирован
            _fsRootsMeta.value = ...
        }
    }
}
```
