# Release Notes — NeuroCode Android 0.8.3

**Дата выпуска:** 4 ноября 2026  
**versionCode:** 30  
**Тема выпуска:** Экран «Доступ к файлам»

## Обзор

Версия 0.8.3 улучшает интерфейс управления корнями доступа к файловой системе Android (Storage Access Framework), добавляя метаданные, быстрые пресеты стандартных папок и удобное управление разрешениями.

## Что нового

### Список корней с метаданными

Каждый выданный корень файловой системы теперь отображается информативной карточкой:

- **Понятное имя папки** (displayName) — например, «Downloads», «Documents», «DCIM»
- **Дата выдачи разрешения** в формате `dd.MM.yyyy` (например, «Выдан 04.11.2026»)
- **Полный URI** для отладки (обрезается при длинных путях)
- **Кнопка «Отозвать»** — удаляет разрешение одним тапом

### Быстрые пресеты

Четыре новые кнопки-пресета над полем добавления корня открывают системный выбор папки с предустановленным каталогом:

- **Загрузки** → `/storage/emulated/0/Download`
- **Документы** → `/storage/emulated/0/Documents`
- **Изображения** → `/storage/emulated/0/Pictures`
- **Вся память** → корень внешнего хранилища

Пресеты используют `Intent.EXTRA_INITIAL_URI` для удобства навигации.

### Миграция формата хранения

- Новый формат: `fsRootsWithTimestamps: Map<String, Long>` (URI → timestamp)
- Старый формат `fsRoots: List<String>` помечен как `@Deprecated`, но поддерживается
- Автоматическая миграция при добавлении нового корня
- Обратная совместимость с версиями 0.8.0–0.8.2

### Архитектура

```kotlin
// Модель данных в SettingsViewModel
data class FsRootMeta(
    val uri: String,           // content://com.android.externalstorage.documents/tree/...
    val grantedAt: Long,       // Unix timestamp в миллисекундах
    val displayName: String    // "Downloads", "Documents", etc.
)

// Пресеты
enum class PresetType {
    DOWNLOADS,   // Environment.DIRECTORY_DOWNLOADS
    DOCUMENTS,   // Environment.DIRECTORY_DOCUMENTS
    PICTURES,    // Environment.DIRECTORY_PICTURES
    ALL          // Environment.getExternalStorageDirectory()
}
```

Метаданные собираются при каждом изменении настроек:
1. `settings.fsRootsWithTimestamps` → список URI с timestamp
2. `FilesystemAccessTool.roots(uris)` → список DocumentFile с displayName
3. Объединение → `List<FsRootMeta>`

## Известные ограничения

- **Индикатор в чате** на момент 0.8.3 не был реализован; добавлен в 0.8.5 через `ChatMessage.fsRootName`
- Пресеты открывают системный пикер с предзаполненной папкой, но пользователь может выбрать любой другой каталог
- Формат даты фиксирован (`dd.MM.yyyy`), без локализации формата по языку устройства

## Обновление

При обновлении с версий 0.8.0–0.8.2:
- Старые корни (`fsRoots: List<String>`) мигрируют автоматически при добавлении первого нового корня
- Если новые корни не добавляются, старые остаются в формате списка и продолжают работать
- Миграция необратима: после добавления нового корня старый формат очищается
